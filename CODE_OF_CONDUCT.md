# Code of Conduct

We want participation in this project to be welcoming, respectful, and free of
harassment. This applies regardless of a person's age, disability, ethnicity,
gender identity or expression, experience, nationality, appearance, race,
religion, or sexual orientation.

## Expected behavior

- Treat people with respect and kindness.
- Make room for differing views and experiences.
- Give and receive constructive feedback in good faith.
- Take responsibility for mistakes and their effects.

## Unacceptable behavior

- Harassment, threats, or unwanted sexual attention.
- Insults, personal attacks, or deliberate disruption.
- Sharing someone's private information without permission.
- Other conduct that would reasonably make this a hostile or unsafe community.

## Scope and enforcement

This code applies to the project's GitHub spaces and whenever someone
represents the project in public. The project maintainers may edit or remove
contributions that violate it and may restrict participation, including
temporarily or permanently.

Report behavior to the project maintainer through the contact options on
[GitHub](https://github.com/NoRain211). For behavior in a GitHub issue or pull
request, GitHub's **Report content** feature is also available. Please do not
post private incident details in a public issue.

This code is adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
